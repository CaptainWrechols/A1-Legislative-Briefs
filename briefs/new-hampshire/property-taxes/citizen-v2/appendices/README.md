# Appendices — NH1 Property Taxes Legislative Brief

Long-form detail behind the NH1 Property Taxes Legislative Brief. 530 bills
are in the set for 2020–2026; 445 policy bills carry the headline numbers (50
context bills and 36 biennium-carryover duplicates are kept for audit).
2020–2024 discovery is certified against the complete OpenStates bulk
universe (5,467 bills, every title swept and every candidate reviewed);
2025–2026 comes complete from the official state database.

| File | Contents |
|---|---|
| `A-bills-overview.md` | Every bill: plain topic, theme, result, relevance tier |
| `B-theme-scorecards.md` | Theme-by-theme record with history baskets |
| `C-votes-and-support.md` | Every floor roll call with party splits; high-support non-enactments |
| `D-sponsors-and-people.md` | Frequent primary sponsors; per-bill sponsor lists |
| `E-bill-path-details.md` | Where each policy bill ended, from official dockets |
| `F-data-limits.md` | What this record can and cannot say |
| `G-bill-grid.md` | Bill-by-bill grid: year, number, subject, prime sponsor, House vote, Senate vote, Governor's action |
| `H-hb2-budget-trailer.md` | Tax and revenue sections inside HB2 (2021, 2023, 2025) with whole-bill votes |
| `I-sources-and-review-notes.md` | Claim-to-source map, collection notes, certification, review status |

(The Nevada packets use Appendix G for introduced-vs-final text comparisons;
the NH record has no version diffs, so G here is the bill-by-bill vote grid.)

Print/Word versions: `appendices-print.html` (browser Print → Save as PDF),
`appendices.docx`, and the one-document Master Appendix
(`NH1-Property-Taxes-Master-Appendix.docx` / `.pdf`).
