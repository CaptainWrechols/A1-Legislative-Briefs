# Appendices — Responsive Elected Leaders in South Carolina (citizen-v2)

Detail behind the two-page front brief. Each appendix is print-friendly and
self-contained; together they carry everything the front brief summarizes.

| File | What's inside |
|---|---|
| `A-bills-overview.md` | One row per curated bill (189), grouped by theme: what it tried, tier, result, where it stopped |
| `B-theme-scorecards.md` | Per-theme deep dives with history baskets and certainty labels |
| `C-votes-and-support.md` | Every passage/adoption-type floor roll call, verbatim; plus the "high support, not enacted" table |
| `D-sponsors-and-people.md` | Frequent lead sponsors; verbatim sponsor line per policy bill |
| `E-bill-path-details.md` | Milestone paths for the 15 measures the front brief leans on |
| `F-data-limits.md` | What the data cannot say (no committee tallies, no party labels, keyword scope, resolutions vs. laws) |
| `G-budget-provisos.md` | Ethics/elections provisos in each budget year, incl. the new FY 2026-27 ethics-filing rule and the election-litigation power |
| `H-proposal-crosswalk.md` | The six Phase 2 citizen proposals [P-…] matched against the record |
| `I-sources-and-review-notes.md` | Claim-to-source map, collection notes, review status |

Print versions: `appendices-print.html` (combined, with table of contents)
and `appendices.docx` (Word). Bill ids read `2021-22 S38` (session years +
number); the same bill number can recur in different sessions and means a
different bill each time.
