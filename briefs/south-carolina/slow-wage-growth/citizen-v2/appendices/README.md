# Appendices — Slow Wage Growth in South Carolina (citizen-v2)

Detail behind the two-page front brief. Each appendix is print-friendly and
self-contained; together they carry everything the front brief summarizes.

| File | What's inside |
|---|---|
| `A-bills-overview.md` | One row per curated bill (133), grouped by theme: what it tried, tier, result, where it stopped |
| `B-theme-scorecards.md` | Per-theme deep dives with history baskets and certainty labels |
| `C-votes-and-support.md` | Every passage-type floor roll call, verbatim; plus the "high support, not enacted" table |
| `D-sponsors-and-people.md` | Frequent lead sponsors; verbatim sponsor line per policy bill |
| `E-bill-path-details.md` | Milestone paths for the 15 bills the front brief leans on |
| `F-data-limits.md` | What the data cannot say (no committee tallies, no party labels, keyword scope) |
| `G-budget-provisos.md` | Wage/workforce provisos in each budget year, incl. SC WINS amounts and state-employee raises |
| `H-proposal-crosswalk.md` | The four Phase 2 citizen proposals [P-…] matched against the record |
| `I-sources-and-review-notes.md` | Claim-to-source map, collection notes, review status |

Print versions: `appendices-print.html` (combined, with table of contents)
and `appendices.docx` (Word). Bill ids read `2021-22 H3144` (session years +
number); the same bill number can recur in different sessions and means a
different bill each time.
